Phần 1: Danh sách 15 field types trong cấu hình fields

Nguồn định nghĩa type: frontend/src/components/admin/FieldManager.jsx (FIELD_TYPES). Mỗi field lưu 1 dòng trong bảng field_definitions. Trường source_type = fixed nghĩa là cột thật trong DB, source_type = json nghĩa là lưu trong cột custom_data (JSON) của record.

1. text Văn bản ngắn (1 dòng)

Mô tả: Ô nhập liệu 1 dòng, render thẻ <input type="text">. Dùng cho tên, địa chỉ, mã số ngắn. Có placeholder, validation (min/max length, pattern).

Cấu trúc JSON (field definition):

{
  "key": "owner_name",
  "label": "Tên chủ sở hữu",
  "type": "text",
  "source_type": "fixed",
  "required": 1,
  "placeholder": "Nhập tên chủ sở hữu",
  "validation": { "minLength": 2, "maxLength": 255 }
}

Giá trị lưu: "Nguyễn Văn A" (chuỗi)

Ví dụ thực tế: Tên chủ sở hữu mặt bằng, địa chỉ ĐKKD, mã số thuế, số tài khoản.

2. textarea Văn bản dài (nhiều dòng)

Mô tả: Khung nhập nhiều dòng, render thẻ <textarea rows="3">. Dùng cho mô tả, ghi chú.

Cấu trúc JSON:

{
  "key": "description",
  "label": "Mô tả",
  "type": "textarea",
  "source_type": "fixed",
  "required": 0,
  "placeholder": "Mô tả đề xuất"
}

Giá trị lưu: "Mặt bằng góc 2 mặt tiền, gần chợ, xe ra vào thuận tiện."

Ví dụ thực tế: Mô tả đề xuất trạm, ghi chú nội bộ.

3. number Số

Mô tả: Ô nhập số (<input type="number">). Cấu hình thêm: number_format (integer/decimal), decimal_places, display_format (plain/comma/dot/space — vd 1,000 / 1.000 / 1 000), unit (đơn vị hiển thị như m², VNĐ/kWh, %).

Cấu trúc JSON:

{
  "key": "dien_tich_mat_bang",
  "label": "Diện tích mặt bằng (m²)",
  "type": "number",
  "source_type": "json",
  "number_format": "decimal",
  "decimal_places": 2,
  "display_format": "comma",
  "unit": "m²"
}

Giá trị lưu: 120.5 (số)

Ví dụ thực tế: Vĩ độ 10.762622, kinh độ 106.660172, diện tích 120.5 m², giá niêm yết 650000 (VNĐ), tỷ lệ % TMT 70.

4. email Thư điện tử

Mô tả: Ô nhập email (<input type="email">), trình duyệt + backend tự validate định dạng xxx@yyy.zzz.

Cấu trúc JSON:

{
  "key": "contact_email",
  "label": "Email liên hệ",
  "type": "email",
  "source_type": "json",
  "required": 0,
  "placeholder": "Nhập email"
}

Giá trị lưu: "chudaidu@example.com"

Ví dụ thực tế: Email chủ đầu tư để gửi hợp đồng (hiện proposals chưa dùng, dùng ở entity users).

6. url Đường dẫn website

Mô tả: Ô nhập URL (<input type="url">), yêu cầu có http(s)://. Hiển thị dạng link bấm được.

Cấu trúc JSON:

Ví dụ thực tế: Link Google Maps vị trí mặt bằng (hiện proposals chưa dùng).

7. date Ngày

Mô tả: Chọn ngày (<input type="date">). Cấu hình date_format hiển thị (vd DD/MM/YYYY) và timezone.

Cấu trúc JSON:

  "type": "date",
  "source_type": "json",

Giá trị lưu: "2026-03-15" (YYYY-MM-DD)

Ví dụ thực tế: Ngày khảo sát mặt bằng 15/03/2026 (hiện proposals lưu thời gian lắp đặt/nghiệm thu dạng text).

8. datetime Ngày + giờ

9. boolean Đúng / Sai (checkbox)

{
  "key": "da_ky_hop_dong",
  "label": "Đã ký hợp đồng",
  "type": "boolean",

Giá trị lưu: true / false

Ví dụ thực tế: Đánh dấu "Đã ký hợp đồng" (hiện proposals chưa dùng).

10. select Chọn 1 giá trị

Mô tả: Dropdown chọn 1 giá trị, hiển thị dạng badge màu. 2 nguồn dữ liệu: (a) nhập tay options: [{label, value, color, borderRadius}] + option_style; (b) lấy từ Data List (data_list_id + data_list_column). Hỗ trợ select nối tầng (cascading) qua parent_field + relation_key.

Cấu trúc JSON (nhập tay):

{
  "key": "mo_hinh_dau_tu",
  "label": "Mô hình đầu tư",
  "type": "select",
  "source_type": "json",
  "required": 1,
  "options": [
    { "label": "Nhượng quyền", "value": "NQ", "color": "#166534", "borderRadius": "rounded" },
    { "label": "Tự đầu tư", "value": "TDT", "color": "#eab308", "borderRadius": "rounded" },
    { "label": "Liên kết", "value": "LK", "color": "#3b82f6", "borderRadius": "rounded" }
  ]
}

Cấu trúc JSON (từ Data List + cascading):

{
  "key": "xa_phuong",
  "label": "Xã phường",
  "type": "select",
  "data_list_id": 4,
  "data_list_column": "xa",
  "parent_field": "province",
  "relation_key": "tinh"
}

Giá trị lưu: "NQ" (1 value)

Ví dụ thực tế: Trạng thái PENDING/REVIEWING/APPROVED/REJECTED, mô hình NQ/TDT/LK, Tỉnh → Xã phường (chọn tỉnh lọc ra xã).

11. multiselect Chọn nhiều giá trị

Mô tả: Như select nhưng tick chọn được nhiều giá trị cùng lúc (hiển thị nhiều badge). Cùng cấu hình nguồn dữ liệu như select.

Cấu trúc JSON:

{

  "label": "Tiện ích xung quanh",
  "type": "multiselect",

    { "label": "Bệnh viện", "value": "benh_vien" }

Giá trị lưu: ["cho", "truong"] (mảng)

Ví dụ thực tế: Tiện ích xung quanh trạm: chợ + trường học (hiện proposals chưa dùng).

12. file Tệp đính kèm

Mô tả: Upload file qua POST /api/files/upload (giới hạn 10MB). Cấu hình file_config: {images, videos, documents, maxSize, multiple}. Xem được ảnh, video, PDF, Word, Excel ngay trên web.

Cấu trúc JSON:

{
  "key": "site_images",
  "label": "Hình ảnh hiện trường",
  "type": "file",
  "source_type": "json",
  "file_config": { "images": true, "videos": false, "documents": true, "maxSize": 5, "multiple": true }
}

Giá trị lưu: [{"id": 12, "name": "mat-bang.jpg", "url": "/uploads/..."}]

Ví dụ thực tế: Hồ sơ pháp lý (sổ đỏ scan PDF), hình ảnh hiện trường mặt bằng.

13. formula Công thức tự tính

Mô tả: Field chỉ đọc, hệ thống tự tính. 2 chế độ (compute_mode): pre = tính ngay trên form lúc nhập; post = tính sau khi tạo record (dùng được id, user tạo...). Có 26 hàm: ROUNDUP, IF, CONCAT, LEN, LPAD, TODAY... Cấu hình outputType/outputFormat/decimalPlaces/unit.

Cấu trúc JSON:

{
  "key": "ma_de_xuat",
  "label": "Mã đề xuất",
  "type": "formula",
  "formula_config": {
    "compute_mode": "post",
    "expression": "CONCAT(mo_hinh_dau_tu, '_', ma_tinh, '_', LPAD(SEQ(...), 4, '0'))",
    "referencedFields": ["mo_hinh_dau_tu", "ma_tinh"],
    "outputType": "text"
  }
}

Giá trị lưu: "NQ_SG_0007"

Ví dụ thực tế: Mã đề xuất NQ_SG_0007, người đề xuất "Nguyễn Văn A (SALES)", tổng chi phí tự đầu tư.

14. password Mật khẩu

Mô tả: Ô nhập mật khẩu (<input type="password" autocomplete="new-password">), ký tự bị che. Bỏ trống = giữ nguyên. Backend hash bằng bcrypt, không lưu plaintext.

Cấu trúc JSON:

{
  "key": "password",
  "label": "Mật khẩu",
  "type": "password",
  "source_type": "fixed",
  "required": 0,
  "placeholder": "Để trống = giữ nguyên"
}

Giá trị nhập: "123456" → lưu hash "$2b$10$..."

Ví dụ thực tế: Đặt/đổi mật khẩu user (hiện proposals không dùng, dùng ở entity users).

15. table Bảng con nhiều dòng

Mô tả: Bảng nhập liệu con ngay trong form: thêm/xóa dòng, mỗi cột tham chiếu 1 field type khác (number/select/date...), cột có thể gắn công thức riêng và dòng tổng (SUM/AVG/MIN/MAX/COUNT). Cấu hình source_config: {columns: [{key, label, column_type, width, required, formula, footer_formula}], min_rows, max_rows}.

Cấu trúc JSON:

{
  "key": "hang_muc_dau_tu",
  "label": "Hạng mục đầu tư",
  "type": "table",
  "source_type": "json",
  "source_config": {
    "min_rows": 0,
    "max_rows": 10,
    "columns": [
      { "key": "ten", "label": "Hạng mục", "column_type": "text" },
      { "key": "so_luong", "label": "SL", "column_type": "number" },
      { "key": "don_gia", "label": "Đơn giá", "column_type": "number" },
      { "key": "thanh_tien", "label": "Thành tiền",
        "column_type": "number", "formula": "so_luong * don_gia",
        "footer_formula": "SUM" }
    ]
  }
}

Giá trị lưu:

[
  { "ten": "Trụ CCS2 60kW", "so_luong": 2, "don_gia": 180000000, "thanh_tien": 360000000 },
  { "ten": "Trạm biến áp", "so_luong": 1, "don_gia": 250000000, "thanh_tien": 250000000 }
]

Ví dụ thực tế: Bảng kê hạng mục đầu tư của trạm (hiện proposals tách sẵn thành các field number riêng thay vì dùng table).
