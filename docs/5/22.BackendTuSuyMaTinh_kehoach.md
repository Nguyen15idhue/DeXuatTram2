**Ngày tạo**: 04/09/2026
**Trạng thái**: Hoàn thành 04/09/2026 (chờ user check thủ công)
**Nguồn**: Yêu cầu user — form chỉ chứa ô Tỉnh/Thành phố; `ma_tinh`/`vung_mien` không cần hiện trên form, backend tự suy từ tên tỉnh. Kể cả admin gỡ field khỏi form, API gọi tay hay import thiếu cột mã đều chạy.

**Nguyên tắc**: server là nguồn duy nhất quyết định mã/vùng từ tên tỉnh; giá trị client gửi lên (nếu có) bị ghi đè.

## Bước 1 — Hàm tra mã theo tên tỉnh

- **Làm**: thêm hàm trong `dataListService` (VD `getDiaGioiByTenTinh`): đọc rows `dm_tinh`, khớp `ten_tinh` tuyệt đối trước, fallback trim + lowercase; trả `{ma_tinh, vung_mien}` hoặc `null`.
- **Yêu cầu cần đạt**: khớp đúng 34/34 tên hiện có; tên lạ/trống → `null` (không đoán mò).
- **Test**: "Thành phố Hà Nội" → `HNO/Bắc`; "  tỉnh đắk lắk " → `DLK/Trung`; "Tỉnh Không Tồn Tại" → `null`.

## Bước 2 — Luồng create (`proposalService.createProposal`)

- **Làm**: sau `splitData`, lấy `province` từ `dynamicData` → tra hàm Bước 1 → ghi đè `ma_tinh`/`vung_mien` vào `dynamicData` (bỏ qua giá trị client gửi); không tra được → lỗi 400 kèm tên tỉnh (rollback, không insert nửa vời). Transaction + formula giữ nguyên.
- **Yêu cầu cần đạt**: tạo không gửi `ma_tinh` vẫn có mã đúng; gửi `ma_tinh` sai vẫn bị sửa lại; thiếu/tên lạ → 400 rõ ràng.
- **Test**: tạo NQ + "Thành phố Hà Nội" (không gửi mã) → `NQ_HNO_xxxx`; tạo có gửi `ma_tinh: "XXX"` → mã vẫn `HNO`; tạo tỉnh lạ → 400 + không có record mới.

## Bước 3 — Luồng update (user + admin)

- **Làm**: nếu payload có `province` → suy lại mã/vùng, merge vào `custom_data` cũ; `ma_de_xuat` vẫn bị chặn ghi đè/không tính lại (giữ logic hiện tại).
- **Yêu cầu cần đạt**: đổi tỉnh → mã/vùng mới, code cũ giữ nguyên; update không đụng tỉnh → mã/vùng giữ nguyên.
- **Test**: update record sang "Tp Hồ Chí Minh" → `ma_tinh=HCM`, `ma_de_xuat` cũ không đổi; update tên chủ (không đổi tỉnh) → mã/vùng không đổi.

## Bước 4 — Luồng import (preview + confirm)

- **Làm**: preview nới required (thiếu mã nhưng có tỉnh → qua; thiếu cả tỉnh → lỗi); confirm suy từng dòng trước INSERT rồi sinh mã như hiện tại; template giữ cột Mã tỉnh + note "bỏ trống sẽ tự suy".
- **Yêu cầu cần đạt**: file thiếu cột/hàng trống mã nhưng đủ tỉnh → import thành công, mã đúng prefix; file thiếu tỉnh → lỗi đúng dòng.
- **Test**: import 2 dòng (1 thiếu mã, 1 đủ mã sai) → cả 2 ra mã đúng theo tỉnh; import dòng thiếu tỉnh → error row.

## Bước 5 — Form + view (SQL, không code)

- **Yêu cầu cần đạt**: mở form tạo không thấy ô mã; tạo xong table vẫn hiện mã/vùng/tên tỉnh.
