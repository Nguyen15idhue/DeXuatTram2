**Trạng thái**: ⏳ Chưa bắt đầu

### Mục tiêu
Xây dựng hệ thống hàng đợi xử lý đồng bộ, rate limiting, retry.

### Các bước

#### Bước 3.1 — Backend: Queue Service

**Thực hiện**:
- Tạo `backend/src/services/queueService.js`
- In-memory queue: `pending[]`, `processing`, `completed[]`, `failed[]`
- MySQL persistence: lưu status vào `api_queue_logs`
- Functions: `addJob`, `getNextPending`, `updateStatus`, `retry`, `cancel`

**Yêu cầu cần đạt**:
- [ ] `addJob` tạo job mới, lưu vào memory + MySQL
- [ ] `getNextPending` lấy job tiếp theo (sort by priority, created_at)
- [ ] `updateStatus` cập nhật status + timestamps
- [ ] `retry` tăng retry_count, đưa về pending
- [ ] `cancel` set status cancelled

**Checklist test**:
- [ ] Thêm 3 jobs → pending queue có 3 jobs
- [ ] Lấy job → processing = job, pending giảm 1
- [ ] Update completed → completed queue có job
- [ ] Update failed → failed queue có job
- [ ] Retry → job về pending, retry_count tăng
- [ ] Cancel → status = cancelled

---

#### Bước 3.2 — Backend: Queue Worker

**Thực hiện**:
- Tạo `backend/src/workers/queueWorker.js`
- `setInterval` mỗi 2s kiểm tra pending queue
- Xử lý tuần tự (1 job tại 1 thời điểm)
- Delay 1.5s giữa mỗi API call
- Auto-requeue pending jobs khi startup

**Yêu cầu cần đạt**:
- [ ] Worker start khi backend boot
- [ ] Poll mỗi 2s
- [ ] Xử lý serial (không parallel)
- [ ] Delay 1.5s giữa mỗi request
- [ ] Requeue pending jobs khi restart
- [ ] Log mọi hoạt động

**Checklist test**:
- [ ] Backend start → worker chạy
- [ ] Thêm job pending → worker xử lý sau 2s
- [ ] Job processing xong → status completed
- [ ] Job failed → retry đúng số lần
- [ ] Restart backend → pending jobs được requeue
