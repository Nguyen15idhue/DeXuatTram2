## Phase 2 — Field Mapping (15 Types) ✅

### Mục tiêu
Tạo UI ánh xạ 15 field types giữa Proposal và1Office

### Field Mapping Rules — Quy tắc ánh xạ

| Source Type | 1Office Target | Transform |
|-------------|---------------|-----------|
| text | name, address, place_of_address | trim(), max 500 |
| textarea | desc | plain text or HTML |
| number | job_tax (as text) | String(value) |
| email | emails | toLowerCase() |
| phone | phones | Remove - .() |
| url | — (chuyển text) | — |
| date | birthday, job_date | YYYY-MM-DD ↔ DD/MM/YYYY |
| datetime | — (chuyển text) | — |
| boolean | job_tax, is_job_tax | true → "1" |
| select | formal_name, scale_id, cf2 | label hoặc ID |
| multiselect | — (chuyển text) | join(',') |
| file | files | base64 JSON array |
| formula | — (chuyển text) | computed value |
| table | — (chuyển text) | JSON stringify |

### Các bước
