## 4. Thiết kế

### 4.1. `LocationMapModal` — thêm filter + legend (tương thích ngược)

```jsx
<LocationMapModal
  open lat lng title radiusKm onClose
  statusFilter={null | { stations: [...], proposals: [...] }}
/>
```

* `statusFilter = null` → giữ hành vi cũ (hiện tất cả) — dùng cho view trạm.
* Preview create truyền `{ stations: ['ACTIVE','DEPLOYING'], proposals: ['PENDING'] }`; lọc tiếp trong `useMemo nearby` sau điều kiện khoảng cách.
* Thêm state `showLegend` (mặc định `matchMedia(min-width:768px)` như `MapView`) + nút toggle overlay góc phải, tái dùng CSS `.map-legend`; legend lấy từ `getStationStatuses()/getProposalStatuses()` (đã dynamic) rồi lọc theo `statusFilter`.
* Text đếm: `N điểm lân cận (lọc ACTIVE/DEPLOYING/PENDING)` khi có filter.

### 4.2. `DynamicForm` — expose tọa độ

* Thêm prop `onValuesChange({ latitude, longitude })`; bắn trong `handleChange` khi key là `latitude/longitude` (không debounce — parent chỉ check hợp lệ lúc render/lúc bấm).
* Hợp lệ = `parseFloat` finite + lat −90..90 + lng −180..180 (đang gõ dở → disable nút).

### 4.3. Khung modal create theo mẫu view

```
.modal-overlay
  .legacy-modal.popup-detail (flex column, max-height:90vh)
    .popup-header (cố định): [Tạo đề xuất mới] [Preview lân cận] [X]
    .popup-body (flex:1, overflow-y:auto — duy nhất vùng cuộn):
      box dán link Google Maps (MyProposals, giữ nguyên logic)
      DynamicForm fields (KHÔNG còn .form-actions bên trong)
    .popup-footer (cố định): [Hủy] [Lưu]
```

* Nút Lưu ở footer submit form bên trong qua `form="id"` (hoặc ref trigger); validate + báo lỗi giữ nguyên, scroll lỗi nhắm vào `.popup-body`.
* Áp dụng cho cả 2 modal create (chuẩn + nhanh dùng chung khung, khác `formId`).

### 4.5. Đường khoảng cách (mới, cho cả preview + xem bản đồ)

* `LocationMapModal` thêm state `showDistance` (mặc định **tắt**) + nút icon toggle đặt **ngay dưới icon ẩn/hiện chú thích** (cụm controls góc phải của modal).
* Tái dùng pipeline vẽ đường sẵn có, không viết renderer mới: dựng `pairs` từ tâm → từng điểm lân cận đang hiển thị:
  ```js
  { a: { latitude, longitude }, b: { latitude, longitude }, distance_m: _distanceKm * 1000 }
  ```
  truyền vào `MapCanvas pairs={showDistance ? pairs : []}` (cả 2 runtime leaflet/maplibre đã hỗ trợ `setPolylines` + nhãn khoảng cách — xem `map/renderers/README.md`, `MapCanvas.jsx:129-133`).
* `pairs` suy ra từ `nearby` đã lọc → đổi bán kính/filter là đường vẽ lại theo; tắt toggle là gỡ hết đường.
* Luật màu đường (áp dụng chung cả 2 renderer leaflet/maplibre, cả map trùng lặp cũ): `<500m đỏ (#ef4444)` / `<2000m cam (#f97316)` / `>2000m xanh lá đậm (#16a34a)`.
* Áp dụng chung cho preview (create) và "Xem bản đồ" (proposals) vì cùng 1 modal.

### 4.6. `RecordDetailPopup` (proposals)

* Entity `station_proposals`: giữ nút `Xem bản đồ`, thêm legend toggle (dùng modal đã mở rộng, `statusFilter=null`).
* Entity `stations`: không đổi hành vi.

## 6. Trường hợp biên

* lat/lng trống/sai → nút preview `disabled`, không mở modal.
* Đang gõ dở số → vẫn disable tới khi hợp lệ.
* Modal preview đang mở + sửa form → giữ snapshot, không nhảy map.
* API public `getAll` lỗi → modal báo rỗng như view hiện tại (không crash).
* Bán kính 50km nhiều điểm: đường mặc định tắt nên không rối; bật lên mà lag thì giới hạn (vd chỉ vẽ khi < 200 điểm).
* Mobile: legend + đường khoảng cách mặc định đóng; header/footer vẫn cố định.
