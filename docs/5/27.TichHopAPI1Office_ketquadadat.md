### 1Office API — Cách gọi đúng

```
GET https://egr.1office.vn/api/customer/contact/gets?access_token={token}&limit=50
Content-Type: (không cần cho GET)

POST https://egr.1office.vn/api/customer/contact/insert?access_token={token}
Content-Type: application/json
Body: { "code": "...", "name": "...", "type": "..." }
```

**SAI (code cũ):**
- `POST` + `Authorization: Bearer token` + `x-www-form-urlencoded`

**ĐÚNG (test_files chứng minh):**
- `GET` + `access_token` query param (cho read)
- `POST` + `application/json` + `access_token` query param (cho write)
