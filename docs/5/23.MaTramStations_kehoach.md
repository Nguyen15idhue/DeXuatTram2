# Mã trạm stations (`E.HNO0001`) + chuyển mã cũ

**Ngày tạo**: 05/09/2026
**Trạng thái**: Hoàn thành 05/09/2026 (chờ user check thủ công)
**Chốt với user**: numbering riêng từng tỉnh; format `E.{ma_tinh}{4 số}` (VD `E.HNO0001`); mã cũ import từ ngoài vào.

---

## Thiết kế

- Fields mới (`database/23-station-code-fields.sql`): `province` (select từ `dm_tinh`, hiện form 7), `ma_tinh` (server suy, không hiện form), `ma_tram` (formula post, hiện form readonly + view 6).
- Expression: `CONCAT('E.', ma_tinh, LPAD(SEQ(CONCAT('E.', ma_tinh)), 4, '0'))` — số 4 trong formula.
- `ma_tinh` suy server-side bằng `applyDiaGioi` (file 22): thiếu/tên lạ → 400. Client gửi sai vẫn bị ghi đè.
- Chung bảng `proposal_sequences` với prefix `E.*` (không đụng `NQ_*`...).
- `updateStation`: merge `custom_data` + suy lại mã/vùng khi đổi tỉnh; **không tính lại mã** (đã xóa block recompute có sẵn — nó tự sinh mã mới khi đổi tỉnh, sai yêu cầu); chặn client ghi đè field post.
- `createStation` nhận full body (trước đây chỉ 6 field cố định) + transaction.

## Import mã cũ

- Dòng có mã → **giữ nguyên verbatim** (allowlist `stations:ma_tram`; proposals vẫn sinh lại).
- Dòng trống mã → sinh mới (suy tỉnh trước như Cách 2).
- `computePostFormulas` thêm option `excludeKeys` để không tốn sequence cho dòng giữ mã.
- Sau import: mồi sequence từng prefix = max đã có (`GREATEST`, cùng transaction).
- Preview chặn mã trùng (cả với DB lẫn trong file).
