## 1. Bối cảnh & mục tiêu

Hiện tại `MapView` gắn khá chặt với Leaflet; `map_configs` mới mô hình hoá **1 tile layer/provider**. Khi muốn:
- dùng **MapLibre GL JS (vector + WebGL)** cho nhiều mode (đường phố/địa hình/vệ tinh/hybrid, 3D),
- hoặc đổi provider bất kỳ lúc nào,
- hoặc tự host (raster/PMTiles),

…thì cần một **lớp trừu tượng** tách "dữ liệu & cấu hình" khỏi "cách render".

**Mục tiêu:**
1. Chuẩn hoá mô hình cấu hình bản đồ: **Provider (nguồn) — Renderer (cách vẽ) — Layer/Mode (nội dung hiển thị)**.
2. Cải tổ `/admin/map-config` để cấu hình được renderer/provider/mode, có preview đúng renderer.
3. Giữ Leaflet làm mặc định/fallback; thêm MapLibre qua seam.
4. Đảm bảo mọi tính năng map hiện có (marker/cluster, popup, filter, duplicate lines, province labels, location modal, click-to-fill, geolocation) **không hồi quy**.

**Ngoài phạm vi (sơ bộ):** traffic/Street View, chỉnh sửa style chuyên sâu, offline hoàn toàn.

## 3. Nguyên tắc thiết kế

1. **Config-driven**: đổi provider/renderer/mode = đổi dữ liệu trong `map_configs`, không deploy code.
2. **Tách 3 khái niệm**: 
   - **Source/Provider**: nguồn tile (raster XYZ, vector pbf/pmtiles, style.json, DEM, raster vệ tinh).
   - **Renderer**: engine vẽ (`leaflet`, `maplibre`).
   - **Mode/Layer**: tổ hợp layer hiển thị (streets, terrain, satellite, hybrid).
3. **Adapter interface** ổn định cho renderer: `mount`, `setView`, `setLayers`, `addMarkers`, `addPolylines`, `setLabels`, `on`, `destroy`, `flyTo`, `getCenter`.
4. **Graceful fallback**: renderer/nguồn chưa hỗ trợ → cảnh báo + fallback Leaflet (không vỡ map).
5. **Parity trước, nâng cấp sau**: MapLibre phải đạt parity các tính năng hiện có trước khi thêm 3D/mode mới.

## 4. Kiến trúc đề xuất (sơ bộ)

```
map_configs (DB)
  ├─ renderer: 'leaflet' | 'maplibre' | ...
  ├─ default_mode: 'streets' | 'terrain' | 'satellite' | 'hybrid'
  ├─ provider_id
  └─ layers_config: JSON [
       { id, role:'base'|'overlay', type:'raster'|'vector'|'dem'|'hillshade',
         url|style_url|pmtiles_url, subdomains, attribution, opacity, minZoom, maxZoom }
     ]
        ↓
MapConfig (hook)  →  MapRuntime (adapter, interface chung)
        ↓                         ↓
   LeafletRenderer          MapLibreRenderer
```

- **Adapter interface** (định nghĩa tại `components/map/renderers/`):
  - `mount(container, options)`, `setView(center, zoom)`, `setLayers(layers, mode)`,
  - `addMarkers(points, { cluster, onMarkerClick, renderPopup })`,
  - `addPolylines(lines)`, `addProvinceLabels/` `setBoundaries`, `on(event, cb)`,
  - `flyTo`, `getCenter`, `remove()`, `supports({ vector, raster, terrain, clustering })`.
- **`MapCanvas` component** (thay phần Leaflet trong `MapView`): chỉ lo dữ liệu + tương tác, gọi runtime adapter.
- **Catalog provider** trở thành dữ liệu cấu hình (không hardcode logic render).

## 5. Phân kỳ (phases)

| Phase | Nội dung | Kết quả |
|---|---|---|
| **0. Chuẩn hoá mô hình** | Thêm cột `default_mode`, `layers_config` vào `map_configs` (migration tiến tới); map catalog hiện có sang model layer. | Config mới tương thích ngược |
| **1. Refactor Leaflet** | Tách `MapRuntime` + `LeafletRenderer`; `MapView` chỉ còn logic dữ liệu/tương tác. | Hành vi y như cũ, không hồi quy |
| **2. Cải tổ admin** | `/admin/map-config` chọn **renderer + provider + mode**; preview dùng đúng renderer; test kết nối/save. | Cấu hình được mọi thứ |
| **3. MapLibre cơ bản** | `MapLibreRenderer`: base vector (PMTiles/OpenFreeMap) + marker/cluster + popup. | Map chạy bằng MapLibre |
| **4. Parity** | Duplicate lines, province labels, boundaries, LocationMapModal, mini map, filter, geolocation, click-to-fill. | Ngang tính năng Leaflet |
| **5. Mode & 3D** | Modes (streets/terrain/satellite/hybrid) qua layer/style; terrain DEM + hillshade + 3D (tuỳ chọn). | "Google-like" 2.5D |
| **6. Test & rollout** | Playwright parity, feature flag theo config/user, fallback Leaflet, tài liệu. | Chuyển đổi an toàn |

## 6. Tiêu chí "chuyển đổi mượt"

- Đổi provider/renderer/mode **chỉ qua `/admin/map-config`**; không sửa/deploy code.
- Có **fallback** khi renderer/nguồn lỗi (banner + Leaflet/default).
- **Parity checklist** (marker màu theo trạng thái, popup quyền, filter, duplicate, location modal, autofill địa chỉ) đều PASS trên cả 2 renderer.
- Sự kiện `mapconfig:refresh` áp dụng đồng loạt cho mọi mặt map.
- Tài liệu hoá interface adapter + hướng dẫn thêm provider/renderer mới.

## 8. Quyết định đã chốt

**Đã chốt (13/09/2026):**
1. **Renderer mặc định:** giữ **Leaflet**; MapLibre là tuỳ chọn qua config.
2. **Nguồn vector:** hỗ trợ **cả PMTiles self-host VÀ OpenFreeMap**, chọn được trong `/admin/map-config` (không key).
3. **Thứ tự mode:** **streets → satellite → hybrid → terrain**.
4. **3D/terrain:** làm **2D nhiều mode trước cho ổn định**; terrain ưu tiên cuối; **3D để giai đoạn cuối, người dùng tự quyết định sau**.
5. **Fallback:** **tự động về Leaflet** khi WebGL không hỗ trợ / renderer lỗi, kèm cảnh báo.
6. **Admin:** **UI cấu hình trực quan** tại `/admin/map-config` (chọn renderer/provider/mode).
