## 2. Kiến trúc chi tiết

### 2.1. Schema `map_configs` (bổ sung)
```
renderer        VARCHAR(30)   -- đã có: 'leaflet' | 'maplibre'
default_mode    VARCHAR(30)   -- MỚI: 'streets' | 'terrain' | 'satellite' | 'hybrid'
layers_config   JSON          -- MỚI: mảng layer
```
`layers_config` (ví dụ):
```json
[
  { "id":"basemap-vector", "role":"base", "type":"vector",
    "source":"pmtiles", "url":"pmtiles:///tiles/vietnam.pmtiles",
    "style":"https://.../style.json", "attribution":"© OpenStreetMap contributors" },
  { "id":"satellite", "role":"base", "type":"raster",
    "url":"https://server.arcgisonline.com/ArcGIS/rest/services/World_Imagery/MapServer/tile/{z}/{y}/{x}",
    "attribution":"© Esri", "opacity":1 },
  { "id":"labels-overlay", "role":"overlay", "type":"vector",
    "source":"pmtiles", "url":"pmtiles:///tiles/vietnam.pmtiles", "mode":"labels-only" },
  { "id":"hillshade", "role":"overlay", "type":"raster",
    "url":"https://.../hillshade/{z}/{x}/{y}.png", "opacity":0.5, "maxZoom":14 }
]
```
**Mode** = cách tổ hợp layer: `streets` (vector base), `satellite` (raster base), `terrain` (raster/DEM), `hybrid` (raster base + vector labels overlay).

### 2.2. Adapter interface (`components/map/renderers/`)
```js
// mỗi renderer export một factory
createRuntime({ container, options }) -> {
  supports: { raster, vector, terrain, cluster, labels, polylines },
  setView(center, zoom),
  setMode(mode, layers),          // áp dụng tổ hợp layer theo mode
  addMarkers(points, { cluster, onMarkerClick, renderPopup }),
  addPolylines(lines, opts),
  setProvinceLabels(points, show),
  setBoundaries(geojson, show),
  flyTo(position, zoom),
  getCenter(),
  on(event, handler),             // click, moveend, ...
  remove(),
}
```
- `registry.js`: `resolveRenderer(id)` → runtime hoặc fallback Leaflet.
- `MapCanvas.jsx`: component chứa `container`, tạo runtime, đẩy dữ liệu vào; `MapView` dùng `MapCanvas` thay phần Leaflet.

### 2.3. Luồng runtime
```
MapConfig (hook, đọc /map-configs)  →  MapCanvas (chọn runtime theo renderer)
   →  runtime.setMode(default_mode, layers_config)
   →  runtime.addMarkers(visibleStations/Proposals) + addPolylines(pairs) + labels/boundary
   →  sự kiện ngược: onMarkerClick, onMapSelectClick, click-to-fill
```
