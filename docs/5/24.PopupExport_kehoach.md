### Chi tiết bước thực hiện

## Yêu cầu 3: Export theo lọc trùng (3 sheets)

### Mô tả

- Khi đang ở mode check trùng, nút Export xuất 1 file `.xlsx` có **3 sheets**:
  - `ketqua`: STT | Bên A (mã) | Bên B (mã) | Khoảng cách (m) — đúng các cặp đang hiển thị.
  - `Bên A`, `Bên B`: full columns **định dạng giống export tất cả**, mỗi sheet là các record tham gia (distinct theo kind: proposal → sheet Bên A?/station → ...). Quy ước: record kind proposal vào sheet tương ứng phía của nó; gom distinct theo id (1 record chỉ 1 dòng dù xuất hiện nhiều cặp).
- Phụ thuộc Yêu cầu 4 file 21 (cột mã): sheet `ketqua` dùng mã, không dùng id thô.

### Hiện trạng chặn

- Chưa có export nào cho mode trùng; `exportDynamic` chỉ biết xuất 1 entity phẳng.

### Files cần sửa

- `backend/src/services/excelService.js` — builder workbook 3 sheets mới (tái dùng `buildExportColumns` cho sheet Bên A/B + style header có sẵn).
- `backend/src/routes/excel.js` — endpoint mới (VD `POST /api/admin/excel/export/duplicates` nhận `{entity scope, min_m, max_m}` + Swagger).
- `frontend/src/components/DuplicateCheckPanel.jsx` — nút Export trong mode trùng (hiện khi có kết quả).
- Nguồn dữ liệu: **server tính lại** theo cùng `min_m/max_m` (chống giả client), không tin pairs client gửi lên.

### Chi tiết bước thực hiện

#### Bước 3.1: Backend builder 3 sheets

- Tính lại pairs bằng `proximityService.findDuplicates` (scope theo endpoint admin/my).
- Sheet `ketqua`: map pairs → mã (fallback `#id`).
- Sheet Bên A/B: distinct ids theo kind → load full record → columns như export tất cả.

#### Bước 3.2: Endpoint + Swagger + nút Export ở panel

- Admin + my (my chỉ pairs liên quan user — tái dùng scope duplicates).
- Panel: nút Export hiện khi `result` có dữ liệu; gọi đúng endpoint theo trang.

### Yêu cầu cần đạt

- [x] File đúng 3 sheets, tên sheet đúng quy ước
- [x] Sheet `ketqua` khớp y hệt table đang hiển thị (số cặp, thứ tự, distance)
- [x] Sheet Bên A/B đủ columns như export tất cả, không trùng dòng
- [x] Không có cặp nào → file vẫn hợp lệ (sheet ketqua trống + note)

### Checklist test

- [x] Check trùng ra N cặp → export có N dòng sheet ketqua, mã khớp table (`NQ_HNO_0001 ~ NQ_HNO_0002`, `NQ_HNO_0001 ~ E.HNO0001`)
- [x] Sheet Bên A/B đủ field (union columns khi trộn 2 entity), distinct đúng
- [x] My-scope: chỉ record liên quan user (1 cặp)
- [x] Mở bằng Excel/LibreOffice không lỗi định dạng (đọc bằng openpyxl OK)

### Kết quả đã đạt (05/09/2026 — Đạt)

- [x] 2 endpoint mới (admin + my, có Swagger) + nút "Export trùng" trong panel; server tính lại pairs theo min/max (chống giả client); `npm run build` OK

## Yêu cầu 5 (fix kèm): User export bị 403

### Mô tả

- Nút Export ở `/my-proposals` đang gọi endpoint `/admin/excel/*` (`requireAdmin`) → user thường **403**. Làm **sau 25** (đổi thiết kế theo scope role, xem dưới).

### Hướng sửa (chốt khi làm, theo 25)

- Endpoint export theo role thay vì tách user/admin cứng: CTV → filter `user_id` mình; SALES → filter nhánh mình; ADMIN/SUPER → tất cả (đúng rule AGENTS.md #3 + ma trận 25).
- Giữ endpoint admin cũ cho tương thích, gắn scope theo role người gọi.
