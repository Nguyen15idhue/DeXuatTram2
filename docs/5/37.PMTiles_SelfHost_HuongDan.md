# Hướng dẫn self-host PMTiles (Việt Nam) cho MapLibre

> **Ngày:** 13/09/2026 · Liên quan: `docs/5/36.MapLibre_CaiToMap_*`, `AGENTS.md`

## 1. Tổng quan

Hệ thống hỗ trợ 2 nguồn vector cho renderer MapLibre:
- **OpenFreeMap** (mặc định, remote, không key): provider `maplibre-osm`, style `https://tiles.openfreemap.org/styles/liberty`.
- **Self-host PMTiles** (offline/không phụ thuộc dịch vụ): provider `maplibre-self-hosted`.

PMTiles là 1 file duy nhất, client tải qua **HTTP Range request** (206). Frontend phát file từ `frontend/public/pmtiles/`.

## 2. Build Vietnam PMTiles từ OSM (Planetiler)

Yêu cầu: Java 17+, ~700MB dung lượng tạm, ~6GB RAM.

```bash
# 1. Tải Planetiler (bản tương thích Java 17: v0.7.0)
curl -L -o planetiler.jar \
  https://github.com/onthegomap/planetiler/releases/download/v0.7.0/planetiler.jar

# 2. Tải dữ liệu OSM Việt Nam (Geofabrik ~313MB)
curl -L -o vietnam-latest.osm.pbf \
  https://download.geofabrik.de/asia/vietnam-latest.osm.pbf

# 3. Build PMTiles (tự tải thêm water_polygons/natural_earth/lake_centerlines)
java -Xmx6g -jar planetiler.jar \
  --osm-path=vietnam-latest.osm.pbf \
  --output=vietnam.pmtiles \
  --force --download
```

Kết quả mẫu: `vietnam.pmtiles` ~300MB, ~7–8 phút (CPU/mạng tuỳ máy).

## 3. Phát file

```bash
# Đặt file vào thư mục public của frontend
cp vietnam.pmtiles frontend/public/pmtiles/vietnam.pmtiles
```

- Dev (Vite) phục vụ `http://localhost:5173/pmtiles/vietnam.pmtiles` và **hỗ trợ Range** (đã kiểm chứng trả `206`).
- Production: Nginx/Apache phải bật **Range** và `Accept-Ranges: bytes` cho file `.pmtiles`.
- File `.pmtiles` đã được **.gitignore** (`frontend/public/pmtiles/*.pmtiles`) để không commit file nặng.

## 4. Cấu hình trong Admin

Vào `/admin/map-config`:
1. **Renderer** = `MapLibre GL JS`.
2. **Map Provider** = `MapLibre + Self-hosted Tiles`.
3. **Tile URL** = `/pmtiles/vietnam.pmtiles` (đường dẫn tương đối cũng được — app tự thêm origin).
4. **Mode/Layer** = `Đường phố`.
5. **Test kết nối** → báo `PMTiles OK (range OK)`.
6. **Lưu cấu hình**.

Frontend sẽ dùng **style OpenFreeMap liberty** (`frontend/public/pmtiles/liberty-style.json`) và thay nguồn vector sang `pmtiles://<origin>/pmtiles/vietnam.pmtiles` (bỏ source raster `ne2_shaded`). Nhờ đó có đầy đủ **nhãn địa danh tiếng Việt** (quốc gia/tỉnh/thành/phường/xã), tên đường, tên sông, POI. Marker/đường trùng lặp/nhãn tỉnh/ranh giới vẫn hoạt động như lớp phủ.

## 5. Ghi chú

- Glyphs (font nhãn) mặc định lấy từ `https://tiles.openfreemap.org/fonts/{fontstack}/{range}.pbf`. Muốn offline hoàn toàn cần self-host thêm glyphs.
- Mode `satellite`/`hybrid`/`terrain` dùng raster (Esri / OpenTopoMap); mode `streets` dùng vector (OpenFreeMap hoặc PMTiles).
- Đổi nguồn vector = đổi provider + URL trong admin, **không cần deploy code**.
