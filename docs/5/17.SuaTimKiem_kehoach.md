## Yêu cầu 1: Form Builder — Gộp Layout Config vào Preview

### Mô tả
Hiện tại FormBuilder có 2 khu vực riêng biệt: hàng layout config (thêm hàng, chọn cột, sắp xếp) ở trên, và preview form ở dưới. Cần gộp thành một — admin thao tác trực tiếp trên preview.

### Files cần sửa
- `frontend/src/components/admin/FormBuilder.jsx` (534 dòng — sửa lớn)
- `frontend/src/App.css` (thêm CSS cho layout editing trong preview)

### Chi tiết bước thực hiện

#### Bước 1.1: Tách layout controls vào trong preview
- Xóa khu vực "Cấu hình Layout" riêng biệt (lines 337-355)
- Thêm row controls trực tiếp vào mỗi row trong preview:
  - **Row header**: drag handle (grip icon), label "Hàng N", nút xóa hàng
  - **Column selector**: dropdown 1:1 / 1:2 ngay trên row header
  - **Row actions**: nút thêm hàng mới bên dưới mỗi row

#### Bước 1.2: Nâng cấp Drag & Drop
Hiện tại chỉ kéo từ sidebar → ô trống. Cần mở rộng:
- **Cell → Cell**: Kéo trường từ ô A sang ô B (kể cả khác hàng)
- **Cell → Unassigned**: Kéo trường từ ô về vùng "chưa gán"
- **Row reorder**: Kéo hàng để sắp xếp lại thứ tự

Thay đổi hàm:
- `handleDragOver` (line 195): Detect hover trên row boundary (để chèn hàng mới)
- `handleDrop` (line 185): Xử lý cell-to-cell swap/move
- Thêm `handleFieldDragStart`: Ghi lại source row/cell khi bắt đầu kéo
- Thêm `handleRowDragStart/handleRowDrop`: Cho row reorder

#### Bước 1.3: Thêm hàng mới trong preview
- Nút "+ Thêm hàng" xuất hiện **giữa các row** (khi hover)
- Click → chèn row mới tại vị trí đó (không chỉ append cuối)
- `addRow` (line 119): Thêm tham số `insertIndex` (mặc định = cuối)

#### Bước 1.4: Thêm/xóa cột inline
- Mỗi row có dropdown chọn số cột (1 hoặc 2) ngay trên row header
- Khi đổi từ 2 → 1: Nếu ô thứ 2 có trường → chuyển về unassigned
- `updateRowColumns` (line 141): Xử lý Logic khi giảm cột

#### Bước 1.5: CSS cho layout editing
- Row drag handle: cursor grip, hover highlight
- Row controls: layout flex, gap, alignment
- Drop zone between rows: dashed border khi hover
- Cell swap animation: mờ field cũ, hiện field mới

## Yêu cầu 6: Map Config — Sửa tile URL

### Files cần sửa
- `frontend/src/config/tileProviders.js` — sửa URL template
- `frontend/src/pages/admin/AdminMapConfigPage.jsx` — sửa resolveTileUrl logic

### Vấn đề hiện tại

| Provider | Vấn đề | Fix |
|----------|--------|-----|
| Google Maps | Dùng Static Map API, không phải XYZ tiles | Thay bằng tile URL đúng hoặc xóa |
| MapLibre GL JS | Style JSON, không tương thích Leaflet | Đánh dấu "chỉ dùng với MapLibre" hoặc xóa |
| OpenLayers | Không có tile URL | Đánh dấu "chỉ dùng với OpenLayers" hoặc xóa |
| Self-hosted ({domain}) | Placeholder không hợp lệ | Giữ nguyên (admin tự cấu hình) |
| TomTom | Style options nhầm với tile_url_styles | Sửa lại mapping |
| Mapbox | Token cần config | Đúng nhưng cần test |

### Các provider cần fix tile URL

#### Leaflet + OSM (đã đúng, giữ nguyên)
```
https://{s}.basemaps.cartocdn.com/{style}/{z}/{x}/{y}{r}.png
styles: light_all, dark_all, voyager
```

#### Google Maps → cần fix
- Hiện tại: Static Map API (chỉ trả 1 ảnh)
- Fix: Google Maps không có free XYZ tiles → đổi thành "Google Maps (API Key)" và hướng dẫn dùng JavaScript API, không dùng TileLayer
- Hoặc: Đánh dấu "Yêu cầu API Key + JavaScript API" và không test tile URL

#### MapLibre / OpenLayers → phân loại
- Đánh dấu rõ: "MapLibre GL JS" và "OpenLayers" là renderers khác Leaflet
- Nếu dùng Leaflet → không chọn các provider này
- Hoặc: Thêm tile URL fallback cho các provider này (dùng CARTO/OSM tiles)

#### Self-hosted → giữ nguyên
- Để admin tự cấu hình domain
- Khi domain trống → hiển thị placeholder "Chưa cấu hình"

#### TomTom → fix style mapping
- Sửa `tile_url_styles` để match với `style_options` values
- Hoặc dùng `style_options` label làm key thay vì URI

### Chi tiết bước thực hiện

#### Bước 6.1: Phân loại provider
- **Leaflet-compatible**: leaflet-osm, leaflet-self-hosted, mapbox, arcgis, tomtom, here-maps
- **Non-Leaflet**: maplibre-osm, openlayers-osm (đánh dấu rõ)

#### Bước 6.2: Fix tile URL cho từng provider
Sửa `tileProviders.js`:
```
google-maps: {
  tile_url_template: '' (empty, không dùng TileLayer)
  note: 'Sử dụng Google Maps JavaScript API, không tương thích với Leaflet TileLayer'
}

mapbox: {
  tile_url_template: 'https://api.mapbox.com/styles/v1/{username}/{style_id}/tiles/256/{z}/{x}/{y}@2x?access_token={key}'
  (kiểm tra format đúng)
}

here-maps: {
  tile_url_template: 'https://maps.hereapi.com/v3/base/mc/{z}/{x}/{y}/png?style={style}&apiKey={key}'
  (đã đúng, kiểm tra style mapping)
}

tomtom-maps: {
  tile_url_template: 'https://api.tomtom.com/map/1/tile/{style}/{z}/{x}/{y}.png?key={key}'
  tile_url_styles: ['main', 'hybrid', 'satellite'] (dùng label, không URI)
}
```

#### Bước 6.3: Sửa resolveTileUrl logic
- Nếu provider không có `tile_url_template` → hiển thị thông báo "Provider này không tương thích với Leaflet"
- Không fallback về CARTO Light một cách im lặng
- Hiển thị rõ lỗi khi tile URL không hợp lệ

#### Bước 6.4: UI hiển thị lỗi rõ ràng
- Khi tile URL không hợp lệ → hiển thị thông báo đỏ
- Khi provider không tương thích Leaflet → hiển thị warning
- Nút "Test" chỉenable khi tile URL hợp lệ

- [ ] Tùy chỉnh thủ công hoạt động (admin nhập tile URL)
