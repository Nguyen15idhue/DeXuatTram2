# Kế hoạch: Group Table (Repeater) — nhập nhiều dòng trong form

## 1. Mục tiêu
- Trong form đề xuất, 1 field "Danh sách sản phẩm" chứa nhiều dòng.
- Mỗi dòng có 3 ô: sản phẩm (select từ Data List), số lượng (number), tổng giá (number).
- Nút "+ Thêm dòng" / xóa dòng từng dòng. Giống hóa đơn/cart hàng.

## 2. Hiện trạng
- 13 field types hiện tại đều là field đơn (`text`, `number`, `select`, ...), chưa có kiểu bảng lặp.
- Field động lưu trong cột `custom_data` JSON của entity (`source_type = json`).
- `DynamicForm` + `DynamicField` render từng field phẳng; formula chỉ tính trên field phẳng.
- `FieldRenderer` + `DynamicTable` hiển thị 1 giá trị / 1 ô.

## 3. Thiết kế dữ liệu
- Thêm type mới `repeater` (tên gợi ý: `repeater` hoặc `table`).
- 1 field repeater lưu 1 mảng object trong `custom_data`:
```json
"line_items": [
  { "san_pham": "Trụ A", "so_luong": 2, "tong_gia": 500000 },
  { "san_pham": "Trụ B", "so_luong": 1, "tong_gia": 300000 }
]
```
- Config của field (trong `field_definitions`, cột liên quan `source_config`/`options`):
```json
{
  "columns": [
    { "key": "san_pham", "label": "Sản phẩm", "type": "select", "data_list_id": 5, "data_list_column": "san_pham", "required": true },
    { "key": "so_luong", "label": "Số lượng", "type": "number", "required": true },
    { "key": "tong_gia", "label": "Tổng giá", "type": "number", "required": true }
  ],
  "min_rows": 1,
  "max_rows": 20
}
```

## 4. Backend — files cần sửa
- `backend/src/controllers/fieldDefinitionController.js`: thêm `repeater` vào `allowedTypes` (create + update).
- `backend/src/services/fieldDefinitionService.js`: cho phép lưu config cột con.
- `backend/src/services/dynamicUtils.js` (`splitData`/`mergeData`): cho mảng repeater đi qua như dynamic value, không stringify 2 lần.
- `backend/src/middlewares/validators.js`: thêm rule validate repeater — số dòng min/max, validate từng ô theo type con (number/select bắt buộc...).
- `backend/src/services/formulaService.js` (+ `dynamicEngineService.js`): 2 mức —
  - (a) formula theo dòng (VD `tong_gia = so_luong * don_gia`),
  - (b) formula tổng hợp (VD `tong_cong = SUM(line_items.tong_gia)`).
- `FieldRenderer`/`excelService.js`: hiển thị + export (badge "3 dòng" + popup chi tiết; export serialize JSON hoặc `SP1/SL1/Gia1...`).
- Thêm `@swagger` nếu thêm endpoint mới (ưu tiên không thêm endpoint, chỉ thêm type).

## 5. Frontend — files cần sửa
- `frontend/src/components/dynamic/DynamicForm.jsx`: state `formData[line_items]` là mảng; logic thêm/xóa dòng; validate lỗi theo từng dòng/ô; reuse `getFilteredOptions` cho select trong dòng (cascading tỉnh/xã giữ nguyên).
- `frontend/src/components/dynamic/DynamicField.jsx`: thêm case `repeater` render bảng + nút "+ Thêm dòng" / xóa dòng; tái dùng renderer ô hiện tại.
- `frontend/src/components/admin/FormBuilder.jsx`: panel cấu hình cột con (thêm cột, chọn type, gắn Data List cho cột sản phẩm, set required) — giao diện tương tự `DataListManager`.
- `frontend/src/components/dynamic/FieldRenderer.jsx` + `DynamicTable.jsx`: ô repeater hiện gọn ("3 dòng") + popup bảng chi tiết.
- `frontend/src/components/admin/RecordDetailPopup.jsx` + `AdminProposalsPage`/`MyProposalsPage`: xem chi tiết dạng bảng expandable.

## 6. Thứ tự làm (4 bước)
1. Backend chấp nhận type `repeater` + lưu/đọc mảng JSON + validate cơ bản (form chạy được).
2. Frontend render bảng thêm/xóa dòng trong `DynamicForm`/`DynamicField`.
3. Formula theo dòng + tổng cộng (frontend `computeFormula` + backend `formulaService`).
4. Màn hình admin cấu hình cột con + hiển thị đẹp ở bảng/popup/Excel.

## 7. Dữ liệu cũ
- 3 field rời hiện tại (`sản phẩm`, `số lượng`, `tổng giá`) gộp thành 1 field repeater.
- Record cũ cần script migrate (gói 3 giá trị cũ thành 1 dòng) hoặc giữ song song 2 version form.

## 8. Lựa chọn thay thế (đã bác)
- Bảng con `proposal_line_items` (FK → proposals): mạnh khi cần lọc/báo cáo theo từng sản phẩm, nhưng phải thêm table + CRUD routes + JOIN — to hơn nhiều. Với nhu cầu hiện tại, JSON trong `custom_data` là đủ và hợp kiến trúc dynamic hiện có.
