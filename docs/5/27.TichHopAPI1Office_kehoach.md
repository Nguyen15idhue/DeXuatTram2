**Cập nhật**: 09/09/2026 — Redesign: HTML desc template + conditional sections

## 1. Tổng quan

### Mục đích
Tích hợp API 1Office (CRM bên thứ 3) với hệ thống quản lý trạm sạc hiện tại, cho phép đồng bộ dữ liệu đề xuất (proposals) sang hệ thống liên hệ1Office và ngược lại.

### Chiến lược đồng bộ (Redesign)

```
┌─────────────────────────────────────────────────────────┐
│  1Office Contact                                        │
├─────────────────────────────────────────────────────────┤
│  Direct Fields (map trực tiếp)                          │
│  ├── name ← owner_name                                  │
│  ├── phones ← owner_phone                               │
│  ├── emails ← custom_data.email                         │
│  ├── address ← address                                  │
│  └── cf2 ← custom_data.cf2 (label: VIP, VVIP)           │
├─────────────────────────────────────────────────────────┤
│  desc (HTML Template)                                   │
│  ├── Section A: Thông tin cơ bản (luôn hiện)            │
│  ├── Section B: Thông tin khác (expandable)             │
│  ├── Section C: Theo mô hình đầu tư (3 sections điều kiện)│
│  └── Field đã dùng trong desc → KHÔNG map trường khác   │
├─────────────────────────────────────────────────────────┤
│  files (tạo riêng trên1Office, upload base64)           │
│  ├── legal_document (hồ sơ pháp lý)                     │
│  └── site_images (hình ảnh hiện trường)                 │
└─────────────────────────────────────────────────────────┘
```

### Tại sao redesign?
1. 1Office API chỉ lưu 18/28 fields — phần lớn fields không hoạt động
2. Desc field hỗ trợ HTML, render đẹp trên web UI (table, bold, colors)
3. Template HTML linh hoạt theo mô hình đầu tư (NQ/TDT/LK)
4. Đơn giản hóa logic mapping — aggregate vào desc thay vì map từng field
5. Files upload riêng, không embed trong desc

## 4. Database Schema

### 4.1 Bảng api_configs (mở rộng)

```sql
CREATE TABLE api_configs (
  id INT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(100) NOT NULL UNIQUE,
  display_name VARCHAR(200) NOT NULL,
  base_url VARCHAR(500) NOT NULL,
  auth_type ENUM('token','oauth2','api_key','basic') DEFAULT 'token',
  auth_config JSON,
  rate_limit_per_second INT DEFAULT 5,
  rate_limit_per_minute INT DEFAULT 60,
  request_timeout INT DEFAULT 30000,
  is_active BOOLEAN DEFAULT TRUE,
  -- THÊM MỚI: Config cho desc HTML template
  desc_template_config JSON COMMENT 'Cấu hình sections + fields cho desc HTML',
  created_by INT,
  updated_by INT,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  FOREIGN KEY (created_by) REFERENCES users(id) ON DELETE SET NULL,
  FOREIGN KEY (updated_by) REFERENCES users(id) ON DELETE SET NULL
);
```

### 4.2 Bảng api_field_mappings

```sql
CREATE TABLE api_field_mappings (
  id INT PRIMARY KEY AUTO_INCREMENT,
  api_config_id INT NOT NULL,
  entity_type ENUM('proposal','station') NOT NULL DEFAULT 'proposal',
  source_field VARCHAR(100) NOT NULL,
  target_field VARCHAR(100) NOT NULL,
  target_field_type ENUM(
    'text','textarea','number','email','phone','url',
    'date','datetime','boolean','select','multiselect',
    'file','formula','password','table'
  ) NOT NULL,
  is_required BOOLEAN DEFAULT FALSE,
  is_sync_enabled BOOLEAN DEFAULT TRUE,
  default_value VARCHAR(500),
  transform_rule TEXT,
  reverse_transform_rule TEXT,
  lookup_table JSON,
  column_mappings JSON,
  validation_regex VARCHAR(500),
  sort_order INT DEFAULT 0,
  is_active BOOLEAN DEFAULT TRUE,
  -- THÊM MỚI: Đánh dấu field dùng trong desc
  used_in_desc BOOLEAN DEFAULT FALSE COMMENT 'Field này đã dùng trong desc HTML template',
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (api_config_id) REFERENCES api_configs(id) ON DELETE CASCADE
);
```

### 5.3 Condition operators

| Operator | Mô tả | Ví dụ |
|----------|-------|-------|
| `=` | Bằng | `mo_hinh = "NQ"` |
| `!=` | Không bằng | `status != "REJECTED"` |
| `contains` | Chứa | `description contains "sạc"` |
| `>` / `<` | Lớn hơn / Nhỏ hơn | `area > 100` |
| `empty` | Rỗng | `description empty` |
| `not_empty` | Không rỗng | `description not_empty` |

### 5.4 Field conflict rules

```javascript
// Khi user map field sang1Office
function checkFieldConflict(fieldKey, apiConfigId) {
  const config = await getApiConfig(apiConfigId);
  const template = config.desc_template_config;
  
  if (!template) return false; // Chưa có template
  
  const usedFields = template.sections.flatMap(s => s.fields);
  
  if (usedFields.includes(fieldKey)) {
    throw new Error(
      `Field "${fieldKey}" đã được sử dụng trong desc HTML template. ` +
      `Không thể map sang trường 1Office khác. ` +
      `Xóa field khỏi template hoặc đổi mapping.`
    );
  }
  return false;
}
```

## 6. Sync Flow

### 6.1 Insert (Tạo mới)

```
1. Extract data từ station_proposals
   ├── fixed columns → direct fields + template data
   └── custom_data JSON → template data

2. Load desc_template_config từ api_configs

3. For each section in template:
   ├── Check condition (nếu có)
   │   ├── mo_hinh = "NQ" → render model_nq section
   │   ├── mo_hinh = "TDT" → render model_tdt section
   │   └── mo_hinh = "LK" → render model_lk section
   ├── Collect field values
   └── Generate HTML rows

4. Map direct fields
   ├── name ← owner_name
   ├── phones ← owner_phone
   ├── emails ← custom_data.email
   ├── address ← address
   └── cf2 ← custom_data.cf2

5. Load files từ files table
   ├── legal_document → base64
   └── site_images → base64

6. Call 1Office API
   ├── POST /api/customer/contact/insert
   │   ├── code: DXS_{tracking_code}
   │   ├── type: 0 (Cá nhân)
   │   ├── name, phones, emails, address, cf2
   │   ├── desc: htmlContent
   │   └── files: [{name, file}]
   │
   └── Update proposal
       ├── contact_1office_code: DXS_{tracking_code}
       ├── last_synced_data: snapshot
       └── sync_status: synced
```

### 6.2 Update (Cập nhật)

```
1. Check thay đổi
   ├── So sánh current data vs last_synced_data
   ├── Nếu không có gì mới → skip
   └── Có thay đổi → continue

2. Generate HTML mới từ template

3. Load files mới (nếu có)

4. Call 1Office API
   ├── POST /api/customer/contact/update
   │   ├── code: DXS_{tracking_code}
   │   ├── desc: htmlContent (mới)
   │   └── files: newFiles (nếu có)
   │
   └── Update proposal
       ├── last_synced_data: snapshot
       └── last_synced_at: NOW()
```

### 6.3 Trigger update

| Event | Action |
|-------|--------|
| Proposal status thay đổi | Update desc |
| Thêm/sửa file | Update files |
| Sửa chi phí/信息 | Update desc |
| User manually trigger | Update tất cả |
| mo_hinh thay đổi | Update desc (section mới) |

```javascript
// New: aggregate vào desc + files
exports.pushTo1Office = async (proposalIds, apiConfigId, userId) => {
  for (const proposalId of proposalIds) {
    // 1. Extract data
    const proposal = await getProposal(proposalId);
    
    // 2. Map direct fields
    const directFields = mapDirectFields(proposal);
    
    // 3. Generate HTML từ template
    const htmlDesc = await templateService.render(proposal, apiConfigId);
    
    // 4. Load files
    const files = await fileSyncService.loadFiles(proposalId);
    
    // 5. Create job
    await queueService.addJob({
      type: 'push',
      proposal_id: proposalId,
      payload: { ...directFields, desc: htmlDesc, files }
    });
  }
};
```

### 7.3 Template Service

```javascript
// backend/src/services/templateService.js
exports.render = async (proposal, apiConfigId) => {
  const config = await getApiConfig(apiConfigId);
  const template = config.desc_template_config;
  
  if (!template) {
    // Fallback: plain text desc
    return proposal.description || '';
  }
  
  let html = '';
  
  for (const section of template.sections) {
    // Check condition
    if (section.condition) {
      const value = getFieldValue(proposal, section.condition.field);
      if (!evaluateCondition(value, section.condition.operator, section.condition.value)) {
        continue; // Skip this section
      }
    }
    
    // Render section
    html += renderSection(section, proposal);
  }
  
  return html;
};
```

## 11. Risks & Mitigations

| Risk | Impact | Mitigation |
|------|--------|------------|
| Template HTML quá lớn | 1Office reject | Limit desc < 65KB |
| Files quá nhiều | Timeout | Split batch, async upload |
| Condition sai | Section hiển thị sai | Validate conditions |
| Template break khi data null | HTML lỗi | Default values |
| 1Office thay đổi API | Sync fail | Version check, fallback |
| Field conflict | User bối rối | Clear error messages |
