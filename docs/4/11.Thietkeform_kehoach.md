## 2. Layout System — Hiểu đúng

```
Column ratio format: "mobile:desktop"

1:1 → Mobile: 1 cột, Desktop: 1 cột (mỗi hàng 1 ô)
1:2 → Mobile: 1 cột, Desktop: 2 cột (mỗi hàng 2 ô trên desktop)
2:1 → Mobile: 2 cột, Desktop: 1 cột
2:2 → Mobile: 2 cột, Desktop: 2 cột
```

**Ví dụ form Layout "1:2":**
```
Desktop (2 cột):          Mobile (1 cột):
┌──────────┬──────────┐   ┌──────────┐
│ Tên trạm  │ Địa chỉ  │   │ Tên trạm  │
├──────────┼──────────┤   ├──────────┤
│ Vĩ độ    │ Kinh độ  │   │ Địa chỉ  │
└──────────┴──────────┘   ├──────────┤
                          │ Vĩ độ    │
                          ├──────────┤
                          │ Kinh độ  │
                          └──────────┘
```

## 3. Kiến trúc dữ liệu

### 3a. DB: Thêm layout_config vào forms

```sql
ALTER TABLE forms ADD COLUMN layout_config JSON DEFAULT NULL;
```

**Format layout_config:**
```json
{
  "rows": [
    { "id": "r1", "columns": "1:2" },
    { "id": "r2", "columns": "1:2" },
    { "id": "r3", "columns": "1:1" }
  ]
}
```

### 3b. form_fields.config — Mở rộng JSON

```json
{
  "colSpan": 1,
  "rowSpan": 1,
  "rowIndex": 0,
  "colIndex": 0,
  "labelOverride": "Tên trạm",
  "placeholderOverride": "Nhập tên...",
  "requiredOverride": true,
  "readonly": false,
  "conditions": [
    { "field": "status", "operator": "=", "value": "ACTIVE" }
  ],
  "conditionLogic": "AND"
}
```

| Key | Type | Mô tả |
|-----|------|-------|
| `rowIndex` | number | Row index trong layout (0-based) |
| `colIndex` | number | Column index trong row (0-based) |
| `colSpan` | number | Số cột chiếm trong CSS grid (1-2) |
| `rowSpan` | number | Chiều cao: 1=bình thường, 2=textarea kéo dài |
| `labelOverride` | string | Override label (null = dùng field_definitions.label) |
| `placeholderOverride` | string | Override placeholder |
| `requiredOverride` | boolean | Override required flag |
| `readonly` | boolean | Field chỉ đọc |
| `conditions` | array | Điều kiện hiển thị |
| `conditionLogic` | string | "AND" hoặc "OR" |

### Preview Mobile/Desktop

**State:** `previewMode: 'desktop' | 'mobile'`

**Toggle buttons:**
```jsx
<div className="preview-toggle">
  <button 
    className={previewMode === 'desktop' ? 'active' : ''}
    onClick={() => setPreviewMode('desktop')}
  >
    💻 Desktop
  </button>
  <button 
    className={previewMode === 'mobile' ? 'active' : ''}
    onClick={() => setPreviewMode('mobile')}
  >
    📱 Mobile
  </button>
</div>
```

**Preview container có max-width thay đổi:**
```jsx
<div 
  className="preview-container"
  style={{ 
    maxWidth: previewMode === 'mobile' ? '375px' : '100%',
    margin: previewMode === 'mobile' ? '0 auto' : '0',
    border: previewMode === 'mobile' ? '2px solid #e2e8f0' : 'none',
    borderRadius: previewMode === 'mobile' ? '20px' : '0',
    padding: previewMode === 'mobile' ? '16px' : '0'
  }}
>
  {/* Form rows render ở đây */}
</div>
```

**CSS khi mobile mode:**
```css
.preview-container.mobile-mode .form-row {
  /* Override desktop cols → dùng mobile cols */
}
.preview-container.mobile-mode .form-row[data-cols="1:2"] {
  grid-template-columns: 1fr;  /* Mobile: 1 cột */
}
.preview-container.mobile-mode .form-row[data-cols="2:2"] {
  grid-template-columns: 1fr 1fr;  /* Mobile: 2 cột */
}
```

**Khi admin đang ở mobile preview:**
- Drag-drop vẫn hoạt động
- Click field vẫn mở config panel
- Thấy trước form sẽ trông như thế nào trên mobile
- Switch sang desktop để thấy layout 2 cột

**交互流程:**
1. Admin chọn columns ratio cho mỗi row (dropdown)
2. Admin toggle Preview: Desktop/Mobile để xem form trên từng nền tảng
3. Admin kéo field từ Available panel vào col trong form preview
4. Admin click field trong form → hiện Field Config panel
5. Admin cấu hình label, placeholder, required, readonly, rowSpan, conditions
6. Admin nhấn Lưu → save form + form_fields + layout_config

## 5. DynamicForm — Render theo Layout

```jsx
// Backend trả về layout_config + fields với config
const rows = form.layout_config?.rows || [];

// Nếu không có layout_config → fallback render flat (backward-compatible)
if (!rows.length) {
  return fields.map(field => <DynamicField ... />);
}

// Render theo rows
return rows.map(row => {
  const rowFields = fields.filter(f => f.config?.rowIndex === rowIndex);
  return (
    <div className="form-row" data-cols={row.columns}>
      {rowFields.map(field => (
        <div className="form-cell" 
             data-rowspan={field.config?.rowSpan || 1}
             style={{ gridColumn: `span ${field.config?.colSpan || 1}` }}>
          {evaluateConditions(field, formData) && <DynamicField ... />}
        </div>
      ))}
    </div>
  );
});
```

**CSS Grid responsive:**
```css
.form-row[data-cols="1:1"] { --mobile: 1; --desktop: 1; }
.form-row[data-cols="1:2"] { --mobile: 1; --desktop: 2; }
.form-row[data-cols="2:1"] { --mobile: 2; --desktop: 1; }
.form-row[data-cols="2:2"] { --mobile: 2; --desktop: 2; }

@media (max-width: 768px) {
  .form-row { grid-template-columns: repeat(var(--mobile), 1fr); }
}
@media (min-width: 769px) {
  .form-row { grid-template-columns: repeat(var(--desktop), 1fr); }
}
```

## 6. Conditional Visibility

```json
// form_fields.config
{
  "conditions": [
    { "field": "status", "operator": "=", "value": "ACTIVE" },
    { "field": "type", "operator": "!=", "value": "" }
  ],
  "conditionLogic": "AND"
}
```

**Operators:** `=`, `!=`, `contains`, `not_contains`, `>`, `<`, `empty`, `not_empty`

**Evaluate:**
```jsx
const evaluateConditions = (field, formData) => {
  const conditions = field.config?.conditions || [];
  if (!conditions.length) return true;
  
  const logic = field.config?.conditionLogic || 'AND';
  const results = conditions.map(cond => {
    const val = formData[cond.field];
    switch (cond.operator) {
      case '=': return String(val) === String(cond.value);
      case '!=': return String(val) !== String(cond.value);
      case 'contains': return String(val).includes(cond.value);
      case '>': return Number(val) > Number(cond.value);
      case '<': return Number(val) < Number(cond.value);
      case 'empty': return !val;
      case 'not_empty': return !!val;
      default: return true;
    }
  });
  return logic === 'AND' ? results.every(Boolean) : results.some(Boolean);
};
```
