## 1. Bối cảnh & hiện trạng

Pipeline hiện tại (sau kế hoạch 54/55):

```
câu hỏi → rewrite câu nối tiếp → dataTools (deterministic, allowlist)
        → help lexical retrieval → knowledge FULLTEXT (docs)
        → build prompt (PHẦN 0/1/2) → LLM (Gemini chính → OpenRouter dự phòng)
        → redactPII → log assistant_logs
```

Thành phần chính:
- `backend/src/routes/assistant.js` — `POST /api/assistant/ask`, `/ask-stream` (SSE), `GET /status`; rate-limit 30/h/IP.
- `backend/src/services/assistantService.js` — pipeline, prompt, cache `ttlCache` 1h, log.
- `backend/src/services/assistant/{gemini,openrouter,router,provider,dataTools,sse}.js`.
- `backend/src/services/helpService.js` — truy hồi bài help (lexical).
- `backend/src/services/knowledgeService.js` — kho tài liệu nội bộ (gate ADMIN/SUPER/SALES).
- `backend/scripts/index-knowledge.js` — index `AGENTS.md` + `docs/**/*.md` vào `assistant_knowledge` (migration 105).
- `frontend/src/components/help/AssistantChat.jsx` — UI chat (SSE, markdown, card nguồn).

## 2. Mục tiêu & phạm vi

**Mục tiêu:**
- Chatbot trả lời được gần như mọi câu hỏi về hệ thống (chức năng, quy trình, cấu hình, kỹ thuật, xử lý lỗi), chỉ từ chối câu **bị cấm** và câu **ngoài phạm vi**.
- Nhận **ảnh + tài liệu** (≤5MB/file) và trả lời dựa trên nội dung tệp.
- Không làm lộ **dữ liệu nghiệp vụ** (users/stations/proposals/datalists/files/logs), **mã nguồn**, **secret/PII**.

**Trong phạm vi:**
- Mở rộng nguồn kiến thức: code map + function-level + schema digest (chỉ `SUPER_ADMIN`).
- Bổ sung tài liệu biên soạn (system digest/FAQ) làm nguồn chính.
- Guardrail phân loại câu hỏi.
- Multimodal ảnh/tài liệu.
- Tối ưu truy hồi/cache (P0/P1 của docs 55).

**Ngoài phạm vi:**
- Không mở đọc dữ liệu nghiệp vụ.
- Không embedding/vector (Nấc 3) — chỉ khi >500 bài hoặc trượt đồng nghĩa nhiều.
- Không cross-encoder reranker.
- Không lưu lịch sử chat server-side (giữ localStorage).

## 3. Quyết định đã chốt

| # | Hạng mục | Quyết định |
|---|---|---|
| 1 | Dữ liệu nghiệp vụ | **Vẫn chặn** hoàn toàn |
| 2 | Index mã nguồn | **Có** — code map + function-level (bỏ `.css`, `public`, generated) |
| 3 | Gate tri thức code | **Chỉ `SUPER_ADMIN`**; prompt cấm dán code/đường dẫn/secret |
| 4 | Nguồn schema | **Đọc sống `information_schema`** (0 dòng dữ liệu) |
| 5 | Kho code | **Tách bảng riêng** `assistant_code_knowledge` |
| 6 | Tài liệu biên soạn | **Có** — bổ sung system digest/FAQ vào `help_articles` |
| 7 | Câu ngoài phạm vi/cấm | **Từ chối ngắn** + hướng về hệ thống |
| 8 | Loại file | Ảnh (jpg/png/gif/webp) + PDF/Word/Excel/CSV/TXT |
| 9 | Số file/lượt & dung lượng | ≤3 file, ≤5MB/file |
| 10 | Guest | **Dùng được** (rate-limit riêng) |
| 11 | Gemini lỗi khi có file | Thử model thị giác OpenRouter; không có → báo lỗi rõ |
| 12 | Lưu file chat | **Xử lý xong xóa ngay** (memory, không ghi đĩa/bảng `files`) |

## 4. Kiến trúc nguồn kiến thức sau nâng cấp

| Nguồn | Lưu ở | Gate role | Trích dẫn nguồn | Ghi chú |
|---|---|---|---|---|
| Bài help chính thức | `help_articles` | theo role | Có (`#slug`) | Nguồn chính, bổ sung digest/FAQ |
| Tài liệu nội bộ | `assistant_knowledge` | ADMIN/SUPER/SALES | Không | docs + AGENTS (giữ nguyên) |
| Code map + function-level + schema | `assistant_code_knowledge` (mới) | **SUPER** | Không, cấm dán code | Sinh tự động, wipe/rebuild tự do |
| Cấu hình/số đếm live | `dataTools` allowlist | ai cũng hỏi | — | Giữ nguyên allowlist |
| Tệp đính kèm | xử lý trong request | theo role | — | Không lưu |

Luồng prompt mới:
```
PHẦN 0 — DỮ LIỆU THẬT (dataTools allowlist)
PHẦN 1 — BÀI HƯỚNG DẪN CHÍNH THỨC (help_articles, trích dẫn #slug)
PHẦN 2 — TÀI LIỆU NỘI BỘ (assistant_knowledge, ẩn nguồn)
PHẦN 3 — MÃ NGUỒN/SCHEMA (assistant_code_knowledge, CHỈ SUPER, cấm dán code)
PHẦN TỆP ĐÍNH KÈM (ảnh inlineData / text bóc từ tài liệu)
HỘI THOẠI TRƯỚC
CÂU HỎI NGƯỜI DÙNG
```
