## 2. Vì sao TipTap (tóm tắt để lưu hồ sơ)

1. Output **JSON doc** (ProseMirror) → viewer render HTML, AI cắt chunk theo heading/block sạch. Quill ra HTML bẩn, Markdown thân thiện kém với CTV/SALES.
2. Video là **block hạng nhất**: node `youtube` (lazy iframe) + node `videoFile` (`file_id` → `/api/files/:id/...?token=`, `preload="none"`).
3. Ép **chuẩn cấu trúc** được: validate ≥1 H2, mỗi video có title, related phải tồn tại (backend `helpService` chặn khi thiếu).
4. Headless, hợp DaisyUI, tree-shakeable (~80–150KB), MIT free full — CKEditor/TinyMCE nặng 500KB+ và vướng license.
5. Giá phải trả: thêm ~5 package + học extension ~0.5 ngày; bọc sẵn `HelpEditor.jsx` toolbar 12 nút nên người viết không cần biết TipTap.

```sql
help_categories(id, slug UNIQUE, title, icon, sort_order, visible_roles JSON, created_at, updated_at)
help_articles(id, slug UNIQUE, category_id FK NULL, title, summary, content_json JSON,
```
