## 3. Danh mục trường kéo được (source_path) — bổ sung 05/10/2026

Nguyên tắc: **mọi thuộc tính của node đều là 1 field kéo được**, không riêng form điểm/đánh giá. Cú pháp `source_path` lưu ở `automation_sheet_mappings`:

| Nhóm | source_path | Giá trị khi sync | Nguồn |
|---|---|---|---|
| Quy trình | `process.ID`, `process.title`, `process.status`, `process.project_code`, `process.start_plan`... | nguyên văn item | `process/item` |
| Khung node | `node.{id}.node_id`, `node.{id}.type`, `node.{id}.title` | nguyên văn định nghĩa | taskprocess |
| Người thực hiện | `node.{id}.user_ids` (VD `55,72`) | key gốc | taskprocess |
| Người thực hiện (tên) | `node.{id}.user_name` (VD `Nguyễn Hải Nguyên`) | **suy ra**: resolve ID qua `/api/admin/user/gets` (admin token), cache 24h; ID lạ/không resolve → **giữ key gốc** | taskprocess + user map |
| Form hành động | `node.{id}.form.{keyword}` (VD `node.n19.form.{diem_1}`) | giá trị đã chấm từ log (VD `2`); node chưa chấm → để trống | taskprocess + log |
| Task | `node.{id}.period`, `node.{id}.desc`, `node.{id}.start_plan`... | nguyên văn | taskprocess |
| Decision | `node.{id}.condition.{k}` (tên nhánh, VD `Tổng điểm <= 6`) | tên nhánh (điều kiện chi tiết xem ở cây node) | taskprocess |
| Notify | `node.{id}.users`, `node.{id}.user_name`, `node.{id}.content` | như trên (users resolve tên) | taskprocess |
| HTTP | `node.{id}.method`, `node.{id}.url`, `node.{id}.body` | nguyên văn | taskprocess |
| Sự kiện | `node.{id}.object`, `node.{id}.event` | nguyên văn | taskprocess |
| Ký | `node.{id}.userId`/`user_name`, `node.{id}.signers` | như trên | taskprocess |

Ví dụ map hay dùng (n19): `node.n19.user_name` → cột "Người chấm"; `node.n19.form.{diem_1}` → cột "Điểm số"; `node.n19.form.{danh_gia_chi_tiet}` → cột "Đánh giá chi tiết".
